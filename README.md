# Котик 🐱 — знакомства на Telegram Serverless

Бот [@moderuserbottestbot](https://t.me/moderuserbottestbot), работающий без отдельного сервера. Сценарий анкеты основан на шаблоне «Котик» из локального Telegram Bot Builder; реализация написана для SDK Telegram Serverless.

## Команды бота

- `/start` — начать или продолжить заполнение анкеты.
- `/menu` — главное меню или продолжение незавершённого диалога.
- `/profile` — собственная опубликованная анкета.
- `/edit` — изменить анкету с возможностью сохранить текущие значения.
- `/cancel` — отменить правки ранее опубликованной анкеты.
- `/browse` — новые анкеты из того же города с взаимными предпочтениями.
- `/matches` — последние 20 взаимных симпатий и действия блокировки или жалобы.
- `/hide` — скрыть или вернуть готовую анкету в поиск.
- `/delete` — удалить анкету и связанные данные после подтверждения.
- `/help` — справка.
- `/serverless_test` — прежний тест постоянного счётчика.

Анкета включает возраст от 18 до 100 лет, пол, предпочтения, город, имя, описание до 500 символов и фото либо видео до 15 секунд. Прогресс заполнения и черновик сохраняются между вызовами. Публикация требует подтверждения.

В поиске не показываются собственная анкета, скрытые и редактируемые анкеты, уже оценённые пользователи и блокировки в обе стороны. Контакт показывается после взаимного лайка. Старые кнопки карточек и повторные лайки не создают новые совпадения.

Первая версия работает только в личных чатах. Город сравнивается по нормализованному названию без геокодирования: сокращения вроде «СПб» и «Санкт-Петербург» считаются разными городами. Автоматической проверки содержимого фото или текста нет. Старые платёжные команды не реализованы.

## Очистка диалога

После ответа пользователя или нажатия кнопки бот удаляет отслеживаемые сообщения предыдущего шага и входящий ответ. Новый вопрос, меню или пара «фото + подтверждение» остаются. Очистка отслеживает сообщения с момента включения функции; старую историю до обновления не перебирает. Если действие завершилось ошибкой или не создало нового ответа, предыдущий шаг сохраняется.

## Модерация

Владелец задан константой `OWNER_ID` в `tgcloud/lib/admin.js`.

- `/reports` — последние 20 жалоб; жалоба также блокирует пользователя для заявителя.
- `/ban ID` — запретить пользователю доступ и скрыть анкету.
- `/unban ID` — снять запрет; анкета остаётся скрытой до действий пользователя.
- `/setup` — обновить название, описание и меню команд бота.

Команды модерации доступны только владельцу. Блокировки владельца сохраняются отдельно от анкеты.

## Подключение и запуск

Нужен Node.js версии 18 или новее. В BotFather откройте бота, включите Serverless и получите отдельный токен в разделе CLI Access.

```powershell
npm ci
npx tgcloud login
npm run status
```

Токен вводится в приглашении CLI. Не добавляйте его в исходники или GitHub. Папки `.tgcloud/` и `node_modules/` исключены из Git. В автоматизированном окружении CLI принимает `TGCLOUD_TOKEN`.

## Развёртывание

```powershell
npm run deploy
npx tgcloud migrate --safe
```

Развёртывание кода и применение схемы базы — отдельные действия. `--safe` применяет только безопасные изменения схемы.

После первого развёртывания владелец может выполнить `/setup`, затем `/start`.

## Проверки

```powershell
npm test
npm run test:cloud
```

Облачный тест требует `TGCLOUD_TOKEN` в окружении и применённой схемы базы. Он выполняется через официальный механизм `run` CLI без публикации тестовых модулей, заменяет отправку сообщений тестовыми ответами, создаёт временные анкеты с отрицательными идентификаторами и удаляет их в `finally`.

Проверяются валидация, шаги анкеты, публикация, видимость, отмена действий, взаимные предпочтения, повторные лайки, устаревшие карточки, блокировки, жалобы и удаление связанных записей.

## Структура проекта

- `tgcloud/schema.js` — анкеты, решения, симпатии, жалобы, запреты и тестовый счётчик.
- `tgcloud/lib/` — заполнение анкеты, поиск, хранение, интерфейс и модерация.
- `tgcloud/handlers/message.js` — команды и ответы на вопросы анкеты.
- `tgcloud/handlers/callback_query.js` — кнопки анкет и поиска.
- `tests/` — локальные и облачные проверки.
- `tgcloud.jsonc` — конфигурация проекта.
- `docs/tgcloud-sdk.md` — справочник SDK из официального шаблона.

Новые комментарии и JSDoc пишутся на русском языке.

Документация платформы: [Telegram Serverless](https://core.telegram.org/bots/serverless).
