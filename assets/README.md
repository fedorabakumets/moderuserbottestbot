# Логотип «Котика»

Создан встроенным инструментом imagegen для аватара Telegram. Изображение изображает светлого котика с носом в форме сердца на тёплом коралловом фоне, без текста.

- `kotik-logo.png` — исходное сгенерированное изображение.
- `kotik-avatar.jpg` — то же изображение в формате JPG, необходимом методу `setMyProfilePhoto`.

## Точный промпт

```text
Use case: logo-brand. Create one polished square Telegram avatar logo for a Russian dating bot called Котик. Primary subject: a friendly charming cat face with a small heart integrated naturally into its cheek or nose. Modern clean illustrated brand mark with smooth bold shapes, expressive gentle eyes, subtle warm personality, appealing to adults. Centered single emblem, generous safe padding for circular cropping, instantly recognizable at tiny sizes, strong silhouette. Soft warm background, coral or peach accents and cream cat, balanced contrast, tasteful minimal detail. No text, no letters, no watermark, no mockup, no border. Render as a finished high quality raster logo.
```
